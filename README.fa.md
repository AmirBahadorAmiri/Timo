# تیمو (Timo) ⏱
### افزونهٔ کرومی برای مدیریت تسک‌ها و تقویم فارسی

**تیمو** یک افزونهٔ مستقل کروم است که صفحهٔ new tab را با داشبورد `Application → Folder → Task` و یک تقویم کامل فارسی گرد هم می‌آورد. همه‌چیز به‌صورت محلی در مرورگر اجرا می‌شود؛ نه PHPای در کار است، نه دیتابیس سرور و نه نیازی به اتصال اینترنت.

---

## 🆕 تغییرات نسخهٔ ۲٫۰ — تبدیل به افزونهٔ کروم

این نسخه تیمو را از XAMPP بیرون آورد و وارد کروم کرد، و تایمر پومودورو را با تقویم جایگزین نمود:

*   **صفحهٔ new tab:** Manifest V3 (`chrome_url_overrides`) بدون build step و بدون سرور؛ تمام داده‌ها در `localStorage` ذخیره می‌شوند.
*   **تقویم فارسی:** نمای ماهانهٔ خورشیدی با تعطیلات، مناسبت‌های مذهبی و جزئیات قابل کلیک؛ تایمر و تنظیماتش کاملاً حذف شدند.
*   **تسک‌ها فقط دو وضعیت:** حالت «در حال انجام» حذف شد؛ دکمهٔ `✓` به‌طور مطمئن وضعیت Done را عوض میکند و عنوان تسک انجام‌شده خط خورده میشود.
*   **چیدمان و آیکون:** ستون ابزارها باریکتر شد، فضای آزاد‌شده بین پوشه‌ها و تسک‌ها تقسیم میشود و آیکون نوار ابزار از طریق `action.default_icon` ثبت شده است.
*   **ساده‌سازی ساعت:** عنوان، نقطهٔ متحرک و خط تاریخ حذف شدند؛ کارت فقط زمان را نشان میدهد تا تقویم تنها نمای تاریخ باشد.

## 🌟 ویژگی‌های کلیدی

### 🗂 مدیریت تسک‌ها
*   سلسله‌مراتب `Application → Folder → Task`؛ حذف هر والد، زیرمجموعه‌هایش را هم پاک می‌کند.
*   ریل دایره‌ای اپلیکیشن‌ها با لوگوی اختصاصی و حرف اول گرادیانی به‌عنوان جایگزین.
*   یک دیالوگ مشترک برای ساخت و ویرایش تسک: عنوان، توضیح، اولویت و وضعیت.

### ✅ جریان کار تسک‌ها
*   وضعیت‌های `todo` / `done` (انجام‌نشده / انجام‌شده) و اولویت‌های `low` / `medium` / `high`.
*   منوی مرتب‌سازی با گزینه‌های جدیدترین، قدیمی‌ترین، اولویت، وضعیت و الفبایی؛ انتخاب کاربر ذخیره می‌شود.
*   دکمهٔ `⋯`، راستکلیک یا `✓` روی ردیف برای ویرایش، تغییر وضعیت و حذف؛ `⇅` ترتیب را عوض می‌کند.
*   **تسک انجام‌شده:** عنوان آن خط خورده میشود تا کارهای تمام‌شده سریعتر دیده شوند.

### 📅 تقویم فارسی
*   نمای ماهانهٔ خورشیدی با اعداد فارسی، هفته‌های شنبه‌آغاز و جابه‌جایی ماه‌ها.
*   **جزئیات با کلیک:** هر روز را انتخاب کنید تا تاریخ کامل خورشیدی، میلادی و قمری‌اش و مناسبت‌های آن در زیر تقویم نمایش داده شوند.
*   **چیدمان فشرده:** عنوان‌های کوتاه هفته و سلول‌های کوچک، کارت را در ۲۹۰px نگه میدارند تا جزئیات بدون اسکرول دیده شوند.
*   تعطیلات رسمی (نوروز، روز جمهوری اسلامی، رحلت امام خمینی (ره)، پیروزی انقلاب، عید فطر، عید قربان، عید غدیر، عاشورا و جمعه‌ها) و مناسبت‌های ملی و مذهبی با نقطه‌های رنگی مشخص می‌شوند.

### 🎨 رابط کاربری
*   پسزمینهٔ کوهستانی با پنل‌ها و کنترل‌های شیشهای نیمهشفاف.
*   دوزبانهٔ فارسی/انگلیسی با پشتیبانی کامل RTL و فونت Vazirmatn بسته‌بندی شده.
*   تم روشن / تاریک با توکن‌های رنگ متحرک.
*   صفحهٔ کامل به‌عنوان new tab، بدون محدودیت اندازهٔ پاپ‌آپ.

### 💾 داده و بکاپ
*   خروجی و ورودی JSON سازگار با بکاپ‌های تیمو نسخهٔ ۱، با دو حالت **افزودن** و **جایگزینی**.
*   لوگوها به‌صورت data URL درون همان فضای کاری محلی ذخیره می‌شوند تا در بکاپ هم بمانند.

## 🛠 تکنولوژی‌های استفاده شده

تیمو با فناوری‌های سادهٔ وب ساخته شده و به هیچ ابزار نصبی نیاز ندارد:

*   **زبان:** جاوااسکریپت خالص، بدون build step.
*   **معماری:** افزونهٔ کروم Manifest V3، یک صفحهٔ new tab و یک لایهٔ API محلی.
*   **ذخیره‌مسازی:** `localStorage` با کلید `timo.data.v1` برای اپ‌ها، پوشه‌ها، تسک‌ها و لوگوها.
*   **محاسبات تاریخ:** الگوریتم خورشیدی Borkowski به‌همراه `Intl` تقویم اسلامی (Umm al-Qura) برای تاریخ قمری.
*   **رابط کاربری:** HTML، دیالوگ بومی `<dialog>`، منوی راستکلیک سفارشی و CSS custom properties.
*   **طراحی:** CSS دستنویس با توکن‌های رنگ `@property` و فونت Vazirmatn بسته‌بندی شده.

## 🚀 راهنمای نصب و اجرا

۱. مخزن را کلون کنید:

```bash
git clone https://github.com/AmirBahadorAmiri/Timo.git
```

۲. در کروم آدرس **chrome://extensions** را باز کنید.

۳. حالت **Developer mode** را با کلید بالا سمت راست روشن کنید.

۴. روی **Load unpacked** بزنید و پوشهٔ `Timo` را انتخاب کنید (پوشه‌ای که `manifest.json` در آن است).

۵. تب جدیدی باز کنید (`Ctrl+T` یا `⌘T`)؛ تیمو به‌صورت خودکار به‌عنوان صفحه لود می‌شود.

نیازی به زامبپ، PHP، MySQL یا `npm install` نیست.

## 🧭 نحوهٔ استفاده

۱. با کلیک روی **+** در ریل اپلیکیشن‌ها، یک اپ بسازید؛ می‌توانید لوگوی آن را هم در همان دیالوگ اضافه کنید.

۲. اپ را انتخاب کنید، اسم پوشه را بنویسید و **افزودن** را بزنید؛ سپس با **+ تسک جدید** تسک‌های آن پوشه را بسازید.

۳. از `⋯`، راستکلیک یا `✓` روی ردیف برای ویرایش، تغییر وضعیت و حذف استفاده کنید؛ `⇅` ترتیب را تغییر می‌دهد.

۴. در تقویم با `‹` و `›` بین ماه‌ها جابه‌جا شوید و با **امروز** به تاریخ فعلی برگردید؛ با کلیک روی هر روز، تاریخ‌ها و مناسبتها را در زیر تقویم بخوانید.

۵. از **💾** در هدر برای خروجی JSON یا ورود دوبارهٔ آن استفاده کنید و حالت افزودن یا جایگزینی را انتخاب نمایید.

۶. `🌙` تم را عوض می‌کند و `FA/EN` زبان را تغییر می‌دهد؛ هر تب جدید همان داشبورد را باز می‌کند.
